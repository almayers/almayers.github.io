1) Exponents

Students will be able to apply the laws of exponents to simplify and evaluate algebraic expressions involving integer exponents, demonstrating understanding of multiplication, division, and power rules as prerequisites for more advanced algebra concepts.

Exponent Rules: The Basics You Need to Know

An exponent tells you how many times a number (the base) is multiplied by itself.

  • Rule 1: Product of Powers: When multiplying powers with the same base, add the exponents. Example: x2 * x5 = x7
  • Rule 2: Quotient of Powers: When dividing powers with the same base, subtract the exponents. Example: y6 / x2 = y4
  • Rule 3: Power of a Power: When raising a power to another power, multiply the exponents. Example: (x3)2 = x6
  • Rule 4: Power of a Product: When an exponent is outside parentheses, it applies to everything inside. Example: (3x)2 = 9x2
  • Rule 5: Zero Exponent: Any nonzero base raised to the zero power equals 1. Example: x0 = 1
  • Rule 6: Negative Exponents: A negative exponent means you will take the reciprocal. Example: x-3 = 1/x3

2) Solving Linear Equations

Students will be able to solve one-variable linear equations by applying properties of equality and inverse operations, and justify each step algebraically.

What does it mean to solve an equation?

To solve a linear equation means to find the value of the variable that makes the equation true. You can think of an equation like a balance scale. This means, whatever you do to one side, you must do to the other side to keep it balanced.

Step-by-Step Strategy:

  1. Simplify both sides (combine like terms if needed).
  2. Undo addition or subtraction first using inverse operations.
  3. Undo multiplication or division last using inverse operations.
  4. Check your answer by plugging it back into the original equation.

3) Algebraic Expressions

Students will be able to simplify and evaluate algebraic expressions by correctly using order of operations, combining like terms, and applying basic properties of numbers as prerequisites for solving equations.

What is an algebraic expression?

An algebraic expression is a math phrase made up of numbers, variables, and operations (addition, subtraction, multiplication, division). Unlike equations, expressions do not have an equal sign.

Parts of an Algebraic Expression:

  • Variable: A letter that represents an unknown number like x or y.
  • Coefficient: The number in front of a variable. In 5x, it is 5.
  • Constant: A number without a variable like 10 or -2.
  • Term: A part of an expression separated by + or −. Example: In 2x+3, we have two terms: 2x and 3.
