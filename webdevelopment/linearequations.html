Linear Equations

Students will be able to solve one-variable linear equations by applying properties of equality and inverse operations, and justify each step algebraically.

What does it mean to solve an equation?

To solve a linear equation means to find the value of the variable that makes the equation true. You can think of an equation like a balance scale. This means, whatever you do to one side, you must do to the other side to keep it balanced. Your goal is to get the variable by itself on one side of the equation. Below is a step by step strategy you can use for all basic problems.

Step-by-Step Strategy:

  1. Simplify both sides (combine like terms if needed).
  2. Undo addition or subtraction first using inverse operations.
  3. Undo multiplication or division last using inverse operations.
  4. Check your answer by plugging it back into the original equation.

Example 1:

Ex: Solve x + 5 = 12

Since the problem is currently adding by 5, we need to "undo" this by subtracting 5 from both sides.

Solution: x = 12 - 5 = 7

Example 2:

Ex: Solve 3x - 4 = 11

This problem has two steps. First, since the problem is currently subtracting by 4, we must "undo" this by adding 4 to both sides.

Solution Step 1: 3x = 11 + 4 = 15

Next, we have 3x which indicates multiplication, or 3 times x. To "undo" this, we should divide both sides by 3.

Solution Step 2: x = 15 ÷ 3 = 5
